Equativ is a global end‑to‑end media platform that helps advertisers, publishers, and retailers maximize the value of their inventory through AI‑driven technology, advanced curation, and performance‑driven solutions. The company offers tools for campaign planning, media buying, revenue optimization, and retail media, serving clients worldwide with a focus on transparency, sustainability, and innovative ad formats.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Equativ: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
